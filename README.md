# Mobilny Serwis Komputerów i Sieci

Strona internetowa mobilnego serwisu komputerowego i IT działającego w Tarnowie oraz okolicach.

## Cel projektu

Celem projektu jest przedstawienie oferty mobilnego serwisu komputerowego, ułatwienie klientom zapoznania się z usługami i cennikiem oraz zapewnienie wygodnego kontaktu z serwisem.

## Technologie

- **HTML5** - struktura i zawartość strony.
- **CSS3** - wygląd i responsywny układ strony.
- **JavaScript** - skrypty strony.

## Zawartość strony

- Strona główna z prezentacją oferty.
- Podstrona z cennikiem usług.
- Podstrony poszczególnych usług.
- Formularz kontaktowy i mapa Google.
- Galeria zdjęć serwisu laptopów.
- Dane kontaktowe i informacje o obszarze działania.
